Waifu Userbot — это асинхронный юзербот для Telegram, предназначенный для создания дампов (резервных копий) истории чатов. Он сохраняет сообщения, информацию о пользователях, чатах и скачивает аватарки в локальную базу данных PostgreSQL.  \n
✨ Возможности  \n
Сохранение истории: Скачивает сообщения из групп, супергрупп, каналов и личных переписок.
База пользователей: Сохраняет всех участников чата, даже если они не писали сообщений (используется iter_participants).
Аватарки: Скачивает аватарки пользователей и чатов в папку session/avatars и привязывает их в БД.  \n
Умный дамп:  \n
Автоматически: При вступлении в новый чат.  \n
Вручную: Команда /dump для текущего чата.  \n
По ссылке: /dump https://t.me/username (работает даже в ЛС).  \n
PostgreSQL: Использование мощной реляционной БД с ORM SQLAlchemy (Async).  \n
Docker: Полная изоляция и простой запуск.  \n\n
🛠 Установка и запуск  \n
1. Предварительные требования  \n
Установленные Docker и Docker Compose.  \n
Полученные API_ID и API_HASH на сайте my.telegram.org.
2. Клонирование и настройка  \n
Скопируйте проект и создайте файл .env в корневой папке:  \n
# .env
API_ID=1234567  \n
API_HASH=ващ_хэш_тут  \n
3. Первый запуск (Авторизация)
При первом запуске нужно ввести номер телефона и код подтверждения. Так как Docker запускается в фоне, первый раз запустим его интерактивно session/make_session.py - появится файл сессии в корне проекта (docker пока не билдим)
# Сборка контейнера
docker-compose build  \n
4. Запуск в фоне  \n
Теперь можно запустить бота в рабочем режиме:  \n
docker-compose up -d
🎮 Использование (Команды)  \n
/ping	Проверка работоспособности (ответ pong).  \n
/dump	Полный дамп текущего чата/группы (сообщения + участники).  \n
/dump <ссылка>	Дамп чата по ссылке или ID. <br>Пример: /dump https://t.me/durov или /dump @username.<br>Работает даже из Личных Сообщений.  \n
/export_db	(Опционально) Создает .sql дамп базы данных и присылает файл в чат.  \n
📂 Структура данных  \n
Файлы: Аватарки сохраняются в папку проекта: ./session/avatars/.  \n
